# Danial Jeelani - Portfolio

A modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS, featuring a Bauhaus-inspired design aesthetic.

## 🚀 Features

- **Modern Design**: Bauhaus-inspired dark theme with red-orange accents
- **Responsive**: Fully responsive design optimized for all devices
- **Smooth Animations**: Framer Motion animations and smooth scrolling
- **TypeScript**: Full TypeScript support for better development experience
- **Fast**: Built with Vite for lightning-fast development and builds

## 🛠️ Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **UI Components**: shadcn/ui
- **Icons**: Lucide React

## 🏃‍♂️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 📁 Project Structure

```
src/

├── pages/              # Page components
├── lib/                # Utility functions
└── main.tsx           # Application entry point
```

## 🎨 Design System

The portfolio uses a carefully crafted Bauhaus-inspired design system with:
- **Primary Color**: Red-orange (#FF4500)
- **Background**: Dark theme (#262626)
- **Typography**: PP Hatton font for headings
- **Layout**: Grid-based, geometric compositions

## 📱 Responsive Design

The website is fully responsive with breakpoints:
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

- GitHub Pages
- AWS S3
